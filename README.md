# ShiftIQ Landing Page

Landing page de **ShiftIQ**, plataforma de gestión inteligente para talleres automotrices: órdenes de trabajo, telemetría OBD2, inventario, dashboard ejecutivo y app móvil para mecánicos y conductores.

## Descripción

La página presenta de manera visual la propuesta de valor de ShiftIQ:

- Los retos del taller tradicional y la solución integral.
- Módulos: órdenes de trabajo, inventario, OBD2, dashboard ejecutivo, app móvil y multi-sede.
- Segmentos: dueños de talleres y conductores / propietarios de vehículos.
- Planes de precio para talleres y propietarios.
- i18n ES / EN.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts (Outfit)
- Matter.js (footer interactivo)

## Cómo ejecutar el proyecto

```bash
npx serve -l 5500
```

Luego abre: [http://localhost:5500](http://localhost:5500)
